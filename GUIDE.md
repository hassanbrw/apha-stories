# Faceless Studio — Bas 3 qadam

Coding aani zaroori nahi. Claude khud sab karega — tools install, setup,
logins, avatar, video. Aap sirf 3 kaam karo:

---

## 1. Folder rakho

`FacelessStudio.zip` ko double-click karo → `faceless-studio` folder nikal
aayega. Usay **Desktop** par rakho.

## 2. Us folder mein Claude kholo

Claude Code khholo aur **isi `faceless-studio` folder** ko kholo (naya session).

## 3. Claude ko ye ek line likho

> **START-HERE.md parho aur mujhe shuru se set up karo**

Bas. Ab Claude khud:

- zaroori tools install karega (Node, FFmpeg, wagera)
- aap se 3 API keys maangega
- Gemini aur HeyGen ke login browser kholega (aap sirf password / 2FA daalo)
- aap ki tasveer se avatar banayega
- phir aap ki **niche** poochega (competitor channels ya ideas), Nexlev se
  analyze kar ke us niche ka andaz (titles, script, thumbnails) yaad kar lega
- aur phir topic dete hi poori video bana dega

---

## Aap ko sirf ye dena hoga (jab Claude maange)

| Claude maangega | aap do |
|---|---|
| API keys | OpenRouter, ai33, yunwu ki keys |
| browser login | Google (Gemini) + HeyGen ka password aur 2FA |
| avatar | ek saaf chehre wali tasveer (16:9) |
| voice | ElevenLabs ki voice ka andaz (ya id) |
| niche | competitor channels ke link ya apne ideas |

## Video kahan milegi

```
work/<video-ka-naam>/final.mp4     ← poori video
work/<video-ka-naam>/thumbnail/    ← 3 thumbnails
```

## Kuch badalna ho

Claude se seedha kaho — *"avatar 30% kar do"*, *"voice dheemi kar do"*,
*"video 20 minute ki banao"*. Wo khud kar dega.

## Masla ho

Claude se kaho — *"check karo sab theek hai?"* ya *"logs dekho kya hua"*.
Wo khud dekh kar theek kar dega.
